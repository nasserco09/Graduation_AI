# اختبار مطابقة نفس المنتج

## الفرق بين الاختبارين

الاختبار القديم يسأل: هل النتيجة من الفئة الصحيحة، مثل أحذية أو بناطيل؟

الاختبار الجديد يسأل: هل النتيجة تحمل رقم المنتج نفسه الموجود في صورة الاستعلام؟

قد ينجح النظام في إظهار أحذية فقط، لكنه يعرض حذاء مختلفًا. لهذا السبب يجب عدم استخدام دقة الفئة على أنها دقة مطابقة المنتج.

## الصور المطلوبة

اختر مجموعة من المنتجات الموجودة في ملف `data/catalog_metadata_train.json`. لكل منتج التقط أو اجمع صورتين إلى خمس صور جديدة تتضمن اختلافًا حقيقيًا واحدًا أو أكثر:

- زاوية تصوير مختلفة.
- خلفية مختلفة.
- إضاءة مختلفة.
- وجود المنتج مع قطع أخرى.
- جزء ظاهر من المنتج بدل الصورة الكاملة.

لا تستخدم صورة الكتالوج نفسها ولا نسخة مصغرة أو مضغوطة منها، لأن ذلك يجعل الاختبار سهلًا وغير واقعي.

ضع الصور مثلًا في المسار التالي:

```text
datasets/exact_product/queries/
```

## تسجيل الصور في ملف الاختبار

أضف كل صورة إلى قائمة `queries` داخل الملف `evaluation/exact_product_manifest.json`:

```json
{
  "image": "datasets/exact_product/queries/shoe_01_angle_2.jpg",
  "product_id": "00f6e504-7c27-438e-a5d7-bc65e557bb2b",
  "category": "shoes",
  "search_category": "auto"
}
```

يمكن تغيير `search_category` إلى `all` لاختبار البحث دون فلترة، أو إلى `shoes` لاختبار التصحيح اليدوي.

## تشغيل الاختبار

من المجلد الرئيسي للمشروع شغّل:

```powershell
python -m evaluation.exact_product_evaluation
```

ستحفظ النتيجة في:

```text
evaluation/results/exact_product_results.json
```

## المؤشرات الناتجة

- دقة أول نتيجة: نسبة الاستعلامات التي ظهر فيها نفس المنتج في المركز الأول.
- دقة أول خمس نتائج: نسبة الاستعلامات التي ظهر فيها نفس المنتج ضمن أول خمس نتائج.
- دقة أول عشر نتائج: نسبة الاستعلامات التي ظهر فيها نفس المنتج ضمن أول عشر نتائج.
- متوسط الترتيب المتبادل: يعطي درجة أعلى عندما يظهر المنتج الصحيح في ترتيب متقدم.
- دقة الفئة: تقيس صحة توقع نوع القطعة بصورة منفصلة.
- زمن الاستجابة: متوسط زمن البحث لكل صورة.

لا تُنقل أي قيمة إلى مستند التخرج أو العرض التقديمي قبل تشغيل الاختبار بصور حقيقية وحفظ ملف النتائج.
