# نسخة العرض مع إدارة المنتجات rc.8

اعتمد هذا الإصدار في 24 أكتوبر 2026 على `feature/frontend-v2`، بعد دمج تطوير `codex/product-management` المبني على rc.7. تظل التاقات السابقة كما هي. التشغيل من الاختصار المعتاد أو `Start_Demo.cmd` على `127.0.0.1:8000`؛ لا حاجة لفتح PyCharm أو استخدام منفذ التطوير 8001.

## الوظائف الموجودة

- رفع صورة، والبحث الكامل أو تحديد القطعة بواسطة SAM2 بالنقاط المطلوبة والمستبعدة أو بالأدوات اليدوية، ثم مراجعة القصاصة والبحث بها.
- اختيار الكتالوج الأصلي (3,068 صورة) أو المنتجات المضافة من الواجهة الرئيسية، والتصنيف التلقائي أو اليدوي بحسب المصدر.
- إدارة المنتجات: إضافة وتعديل وحذف، وفئة وسعر اختياري وعملة وتوفر، وإضافة صور وإزالتها واختيار الصورة الرئيسية، مع 1–5 صور للمنتج.
- قائمة إدارة قابلة للبحث بالاسم والفلترة حسب الفئة والتوفر، وترتيب الأسماء وإحصاءات المنتجات والصور.
- حفظ بيانات المنتج وتغييرات صوره معًا بعد تجهيز الصور الجديدة، ورفض الحفظ أو الحذف من نافذة تحمل مراجعة قديمة من المنتج.

السياق المعتمد هو كتالوج محلي؛ حسابات المحلات وتعدد المتاجر والمبيعات ليست وظائف منفذة ضمن هذه النسخة.

## فحوص الاعتماد من مجلد العرض

| الفحص | النتيجة |
| --- | --- |
| Python | نجح 128 من 128 |
| JavaScript | نجح 26 من 26 |
| اتساق الأدلة والتقسيمات | نجح 55 فحصًا |
| HTTP للبحث والصحة وSAM2 والقصاصات | نجح 32 من 32 |
| تشغيل الإدارة وترحيل البيانات وحفظها | نجح 24 تحققًا |

فحوص الإدارة أنشأت منتج اختبار منفصلًا بصورتين، وعدلت السعر والعملة والتوفر والصور والصورة الرئيسية، وتحققت من انعكاس البيانات في البحث ورفض العمليات المتعارضة. حُذف منتج الاختبار وحده بعد الفحص وتحقق اختفاء صوره. بقيت المنتجات الأصلية الثلاثة وصورها الأربع وتمثيلاتها كما كانت، وفحص SQLite والعلاقات المرجعية ناجح.

فُتحت الواجهة من المنفذ 8000 وأظهرت بيانات الإدارة الأصلية والوظائف الجديدة. الاختبارات تؤكد المسارات المجربة، ولا تمثل دراسة جديدة لدقة البحث أو جودة الأقنعة. لم تتغير النتائج البحثية التاريخية أو النماذج أو الاعتماديات أو إعداد تجهيز الصور.

## البيانات والرجوع إلى إصدار سابق

أُخذت نسخة SQLite متسقة قبل تحديث المخطط في `data/demo_store/backups/presentation-before-rc8-20261024.db`. يضيف المخطط أعمدة مراجعة المنتج وترتيب الصور دون حذف السجلات القديمة.

الرجوع إلى كود rc.7 وحده بعد هذا الترحيل لا يكفي لضمان توافق عمليات إضافة الصور؛ استخدم معه قاعدة متوافقة على نسخة منفصلة، أو النسخة الاحتياطية السابقة، مع حفظ قاعدة rc.8 الحالية أولًا إن أضيفت بيانات جديدة. لا تستبدل بيانات العمل الحالية تلقائيًا للرجوع إلى إصدار قديم.
