# نقطة تثبيت تجربة كتالوج المنتجات

تاريخ التثبيت: 2026-10-06. كود المرحلة الأساسية: a82cba5 على
`codex/ranking-evaluation`. علامة الحفظ: `dev-product-catalog-v1`.
هذه نقطة حفظ للتطوير المحلي؛ ليست إصدارًا بديلًا عن نسخة عرض التخرج.

## المنجز

- تجميع اختياري لصور12 مجموعة أكّد المستخدم أنها لنفس المنتج، مع عرض
  صور المجموعة داخل التفاصيل. باقي الصور تظل مستقلة.
- صفحة مستقلة لإضافة اسم المنتج و1–5 صور له ثم البحث في المنتجات المضافة.
- حفظ منتجات التجربة وصورها وتمثيلاتها في SQLite منفصلة داخل
  `data/demo_store/catalog.db`، مستثناة من Git.
- نجاح94 اختبار Python و14 اختبار واجهة JavaScript. اختبار المتصفح أكد
  الإضافة والبحث والتبديل بين الصور، وبقاء المنتجات بعد إعادة تشغيل الخادم.
- فحص رفض المدخلات غير الصالحة دون إضافة منتج ناقص، وعزل الفهرس الأصلي.

نسخة العرض الأصلية: المجلد `C:/Users/nyousef/PycharmProjects/Graduation_AI`
على فرع `feature/frontend-v2`، علامة `v1.2.0-rc.3`، commit f7c3a27.

`C:/Users/nyousef/.codex/worktrees/ranking-development/Graduation_AI`.

```powershell
$env:GRADUATION_AI_REVIEWED_GROUPS = (Resolve-Path data/reviewed_product_groups.json).Path
./.venv/Scripts/python.exe -u tools/launch_demo.py --port 8001 --no-browser
```

## الحفظ والحدود

عند هذه النقطة أُخذت نسخة احتياطية متسقة لقاعدة التجربة عبر SQLite backup
داخل `data/demo_store/backups/`، وفُحصت سلامتها. الملفات والصور الأصلية
لم تُحذف. الكود محفوظ في Git؛ بيانات التجربة والنسخ الاحتياطية محلية.
نماذج وبيانات train والبيئة الافتراضية مشتركة عبر junctions مع نسخة العرض،
وتُعامل كموارد للقراءة فقط؛ لا تُعدّل أثناء التطوير دون فصلها أولًا.

لم تُدمج تغييرات التطوير في نسخة العرض، ولم تُنقل أي علامة إصدار سابقة.
قبل استيراد داتا كبيرة: افحص المصدر والتنظيم وتكرار المنتجات، وجرّب عينة
في كتالوج مستقل. التجربة الحالية صغيرة ولا تمثل نظام متجر مكتملًا؛ راجع
`DEMO_PRODUCT_ENTRY_AR.md` للحدود والتفاصيل.
