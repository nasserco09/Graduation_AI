# إدارة المنتجات

تطوير 24 أكتوبر 2026 على `codex/product-management`، مبني على `v1.2.0-rc.7` دون تعديل نسخة المناقشة المثبتة. النسخة الجديدة تعمل محليًا على `http://127.0.0.1:8001/demo-catalog.html` داخل checkout التطوير الموجود.

## الاستخدام

- قائمة المنتجات تعرض إجمالي المنتجات، المتوفر وغير المتوفر، وعدد الصور. يمكن البحث بالاسم والفلترة حسب الفئة والتوفر وترتيب الأسماء، أو العودة لترتيب الإضافة.
- زر **إضافة منتج** يفتح نموذج الاسم والفئة والسعر والعملة والتوفر والصور. السعر اختياري ويقبل حتى منزلتين عشريتين. تُقبل الأرقام العربية أيضًا وتُحوّل إلى قيمة عشرية موحدة.
- لكل منتج 1–5 صور. يمكن إضافة صور وإزالة صور واختيار الصورة الرئيسية داخل النموذج، ثم حفظ التغييرات معًا. لا يحدث حذف للصورة المخزنة لمجرد إزالتها من المعاينة؛ يجب حفظ التعديل.
- زر **تعديل المنتج** يغيّر البيانات والصور. الصورة الرئيسية تظهر في قائمة الإدارة؛ البحث يقارن كل صور المنتج ويعرض أفضل صورة مطابقة. الصور المحتفظ بها لا تُشفّر من جديد.
- إيقاف **متوفر للبحث** يخفي المنتج من نتائج البحث، ويُبقيه في الإدارة لإعادته لاحقًا.
- زر **حذف** يعرض اسم المنتج وطلب تأكيد. الحذف يزيل المنتج وصوره وتمثيلاته من قاعدة المنتجات المضافة. يمكن الإلغاء قبل التأكيد.
- رابط البحث الرئيسي يفتح مصدر **منتجاتي المضافة** لاستخدام الصورة الكاملة أو SAM2. البحث السريع داخل الإدارة متاح أيضًا.

## الحفظ والتوافق

تُحفظ البيانات والصور الجديدة في معاملة SQLite واحدة بعد تجهيز كل الصور الجديدة. عند فشل التحقق أو التشفير تبقى البيانات السابقة كما هي. رقم المراجعة يمنع الحفظ أو الحذف من نافذة تعرض نسخة أقدم من المنتج؛ عند التعارض حدّث القائمة وأعد فتحه.

تُضاف أعمدة `revision` للمنتجات و`position` للصور تلقائيًا دون حذف السجلات القديمة. القواعد المحلية والنماذج والبيانات خارج Git. الفهرس الأصلي مستقل ولا يُعاد بناؤه عند إضافة المنتج أو تعديله أو حذفه.

مسار الحفظ الجديد `PUT /api/demo-catalog/products/{id}/content` يستقبل multipart: بيانات المنتج، `revision`، و`image_order` كقائمة JSON من معرفات الصور القديمة و`new:0`… للصور المرفوعة. مسار حذف المنتج `DELETE /api/demo-catalog/products/{id}?revision=…`. بقي مسار تعديل البيانات JSON السابق متاحًا للتوافق.

## التحقق

- نجح 128 اختبار Python و26 اختبار JavaScript، منها اختبارات الذرية وترتيب الصور والتعارض والحذف وتحديث السعر واستبعاد غير المتوفر وتأخر الاستجابات.
- نجح 32 فحص HTTP على الخادم الفعلي، تتضمن البحث الكامل وSAM2 والقصاصات اليدوية.
- تجربة المتصفح: إضافة منتج اختبار بصورتين وسعر عربي، تغيير الصورة الرئيسية، تعديل الاسم والسعر والعملة والتوفر، إزالة صورة وإضافة بديل، فلترة الاسم والتوفر، الرجوع للبحث وعرض السعر الجديد، فتح تأكيد الحذف وإلغاؤه.
- نُفذ حذف منتج الاختبار عبر HTTP وتحقق اختفاء صوره ونتائجه. المنتجات الأصلية الثلاثة وصورها الأربع وتمثيلاتها محفوظة، وكذلك فهرس FAISS وقاعدة العرض الأصلية.
- الأدلة والنسخ الاحتياطية محليًا في `evaluation/cache/product_management/`. هذه فحوص وظائف وليست قياسًا جديدًا لجودة الترتيب أو التحديد.

هذه إدارة كتالوج محلي. حسابات المحلات وصلاحيات المستخدمين وبيانات المحل والمبيعات ليست جزءًا من هذه المرحلة.
