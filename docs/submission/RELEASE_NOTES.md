# LibaasLens university submission materials 2026

**LibaasLens | عدسة لباس**

Academic title: **Visual Fashion Product Search Using Interactive Segmentation**.

Project team: **Nasser Yousef, Noor Yousef and Naeem Basalma**. Academic supervisor: **Dr. Ayman Alsabri**, International University of Technology Twintech.

This submission snapshot collects the report, editable PowerPoint, reading PDF, print-ready poster and English narrated video. The team reviewed and approved the presentation and video and confirmed the local application works on 14 November 2026. Genuine university signatures and stamps are not generated or implied by this release.

## Code and runtime

The source archives below are generated from tag **submission-2026-v1**. The application baseline remains **v1.2.0-rc.9**; this is a submission/branding snapshot, not a new retrieval algorithm or a new model-accuracy claim.
