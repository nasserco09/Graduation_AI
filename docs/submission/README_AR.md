# حزمة تسليم LibaasLens المصححة وفق نموذج BIT

المراجعة: **16 نوفمبر 2026**. الاسم المختصر **LibaasLens | عدسة لباس**، والعنوان الأكاديمي **Visual Fashion Product Search Using Interactive Segmentation**. التخصص المؤكد من الفريق: **Business Information Technology (BIT)**.

تستخدم الحزمة الحالية وثيقة LaTeX المصححة، **93 صفحة**، بمحتويات ومخططات وحالات اختبار مرتبة وفق النموذج المرسل. الفهرس التفصيلي يعرض العناوين الفرعية، مع 19 شكلًا و20 جدولًا و18 مرجعًا مرتبطًا. النسخة السابقة محفوظة تاريخيًا؛ لا تستخدم بدل هذه المراجعة.

| القسم | المحتويات |
| --- | --- |
| `01_Document` | PDF المصحح ومصدر LaTeX القابل للبناء والتعديل |
| `02_Presentation` | PowerPoint المعتمد ونسخة القراءة PDF |
| `03_Poster_and_Brochure` | بوستر 250×140 سم ومصادره، والبروشور المطبوع كما أرسله الفريق دون تعديل |
| `04_Application_Video` | فيديو الاستخدام الصامت v2، 49 ثانية، والنصوص ومصادر التعديل |
| `05_Project_Source` | لقطة الكود من تاق `submission-2026-v3` ورقم commit المصدر |
| `06_Runtime` | ZIP موارد التشغيل المتحقق منه، ودليل الإعداد والبيان |
| `07_Attribution_and_Licenses` | أسماء الفريق والحقوق والاستشهاد وتراخيص المكونات |

ابدأ بـ`START_HERE_AR.html` للفهرس المحلي، وراجع `00_README_AR.txt` للتعليمات. بصمات الملفات في `SHA256SUMS.txt` و`DELIVERY_MANIFEST.json`، وأداة `verify_delivery.py` تتحقق من سلامتها بعد النقل. هذه بصمات تحقق وليست تسجيلًا قانونيًا أو توقيعًا رقميًا.

الحزمة الكاملة تشمل موارد التشغيل الثقيلة؛ يفك ZIP إلى مجلد جديد قبل فتح الفهرس أو إعداد التطبيق. لا تشمل قواعد حساب الفريق أو المنتجات الشخصية أو سجل البحث أو بيئته الافتراضية. لا يحتاج بناء الوثيقة إلى التطبيق أو النماذج أو الداتا؛ يحتاج محرّك LaTeX وحزمه.

التوقيعات والختم الحقيقي تُستكمل من المشرف والجهة الجامعية؛ أماكنها في PDF فارغة. قبول ممثل الفريق للتطبيق والعرض ليس توقيعًا من اللجنة أو ادعاء مراجعتها للوثيقة المصححة.
