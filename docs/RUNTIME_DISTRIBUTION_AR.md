## المحتويات والتشغيل

**تحديث طريقة النقل، 1 نوفمبر 2026:** تعثر رفع ZIP الكامل بسبب مهلة الاتصال، لذلك أُعدت الحزمة نفسها في 28 جزءًا، كل منها حتى 64 MiB. عند توفير ملفات `.part001` إلى `.part028` في الإصدار، نزّلها جميعًا مع `parts_manifest.json` و`assemble_runtime.py` و`Assemble_Runtime.cmd` في مجلد واحد، ثم افتح `Assemble_Runtime.cmd`. يفحص كل جزء ويعيد ZIP الأصلي ويتحقق من بصمته الكاملة قبل الاعتماد. لا تتغير أوزان النماذج أو ملفات التطبيق داخل الحزمة. لا تُفك الأجزاء منفردة. أداة التجميع محفوظة أيضًا في [tools/assemble_runtime.py](../tools/assemble_runtime.py). طريقة النقل هذه لا تعني اكتمال نشر الإصدار؛ يبقى الإصدار مسودة حتى تحقق جميع الأجزاء والملفات المرافقة.

تضم الحزمة الكود المستخدم والواجهة بأصولها المحلية، ونموذجي SigLIP2 Base وSAM2.1 Hiera Base Plus وإعداداتهما، وصور train الأصلية البالغ عددها 3,068، والميتا داتا ومجموعات المنتجات المراجعة وفهرس FAISS الأصلي. تراخيص المصادر وإشعاراتها محفوظة في الحزمة. كل ملف مسجل بحجمه وبصمة SHA-256 في `runtime_manifest.json`.

لا تضم ResNet50 أو EfficientNet أو CLIP أو DINOv2، ولا صور validation/test أو قصاصات التجارب أو مكتبات دفاتر التجارب. لا تتضمن قواعد حساب الفريق أو منتجاته المضافة أو سجلات بحثه، ولا `.venv` أو إعدادات PyCharm. لم تُحذف هذه الملفات من جهاز الفريق.

1. نزّل `Graduation_AI_Runtime_rc9_v1.zip` وفكّه إلى مجلد جديد.
2. وفّر Windows 64-bit وPython 3.12 64-bit؛ البيئة المرجعية 3.12.10.
3. افتح `Setup_Runtime.cmd`. يفحص الموارد ثم ينشئ بيئة افتراضية مستقلة ويثبت 51 مكتبة بإصدارات مثبتة. يحتاج إنترنت، أو مجلد Wheels مطابق عبر `--wheels`؛ لا يعيد تنزيل النموذجين.
4. افتح `Start_Demo.cmd` وانتظر فحص الجاهزية. يبدأ البحث بالكتالوج الأصلي، ومنتجات الإدارة فارغة، وينشئ المستخدم حساب أدمن بنفسه.

التعليمات الكاملة داخل [RUNTIME_README_AR.md](../RUNTIME_README_AR.md). هذه حزمة تشغيل Python وليست EXE؛ مثبت Python ومكتبات Wheels لا يدخلان ZIP. حزمة PyTorch المرجعية تدعم CUDA 13.0، والتطبيق يرجع إلى CPU عند غياب CUDA. سرعة الجهاز الآخر وتوافق تعريفه يحتاجان فحصًا عليه. بعد التثبيت الأول، موارد البحث والواجهة محلية.
