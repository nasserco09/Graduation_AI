\section{Local Presentation Startup}
The reference installation requires the prepared project directory, its Python
environment, both active model directories, original-gallery images, metadata,
and matching FAISS index. On the team's machine, open \texttt{Start\_Demo.cmd}
or its existing desktop shortcut. The launcher checks required assets, uses
the local checkpoints, configures reviewed groups when available, and opens
the browser only after the readiness check succeeds. The normal local address
is \url{http://127.0.0.1:8000/}.

Keep the server process running during the demonstration. If an unrelated or
unready service occupies the port, the launcher reports that condition rather
than stopping another process. The health response should identify
\texttt{clothing\_small\_train}, 3,068 indexed images, and a ready index. The
reported search and segmentation devices can be CPU or CUDA according to the
machine's available inference environment.

\section{Visitor Walkthrough}
\begin{enumerate}[leftmargin=1.8em,itemsep=0.45em]
 \item Choose an image, then select the original gallery or the added-product source.
 \item Search the complete image when it already expresses the intended garment.
 \item For SAM2, place positive points inside the garment and negative points on
 unwanted regions. Inspect the mask and cutout, add points if needed, then accept it.
 \item Alternatively, use a rectangle, polygon, or freehand region and inspect
 the resulting query.
 \item Choose automatic category, a supported explicit category, or unrestricted
 search, and select the result count.
 \item Submit the query. Inspect the returned candidates and, for the original
 gallery, the query-hash verification and category information. A similar item
 is not necessarily the same commercial product.
\end{enumerate}

\section{Product Administration and Recovery}
Open product management and use the local administrator account. A fresh
installation requires the operator to create their own account; the system has
no default credentials. Add a product with 1--5 photos of that product, choose
descriptive fields, and save. Editing supports photo replacement and ordering,
a cover choice, and availability. An unavailable product remains manageable
but is excluded from added-catalogue search. Refresh the list before retrying
a stale-save or stale-delete conflict.

Use export to keep an independent backup. To restore, choose a compatible ZIP,
inspect the validated counts, and confirm only when the replacement is intended.
Preview alone does not replace products. A recovery copy is written before
confirmed replacement and can be downloaded from the automatic-recovery list.
Retain copies outside the working project directory as appropriate for the
operator's local backup practice. This backup covers added products, photos,
and vectors, not model files, the original gallery, or administrator credentials.

\section{Runtime Distribution}
The runtime package includes the active application, local frontend assets,
SigLIP2 and SAM2.1, and the original gallery, metadata, and FAISS index. Unused
checkpoints, development environments, evaluation-query partitions, accounts,
user products, and telemetry are excluded. Run \texttt{Setup\_Runtime.cmd} with
Python 3.12 on Windows x86\_64. Installing dependencies needs internet or compatible
local wheels; Python and wheels are not bundled.

The verified ZIP is 1,815,578,390 bytes, split into 28 parts of at most 64 MiB.
Download all parts together with \path{parts_manifest.json},
\path{assemble_runtime.py}, and \path{Assemble_Runtime.cmd}.
Assembly verifies every part and the original ZIP hash. Extract the ZIP into
a new directory, run setup, then the launcher. Local reassembly passed; the
recorded network transfer was stopped before complete publication.

Source: \url{https://github.com/nasserco09/Graduation_AI}, branch
\texttt{feature/frontend-v2}, tag \texttt{\ApplicationRelease}.
Repository access is required. Large runtime assets are separate; their complete
GitHub publication is not claimed.
