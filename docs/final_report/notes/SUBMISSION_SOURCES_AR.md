# سجل مراجعة وثيقة التسليم

فحوص التطبيق والمراجع: 12 نوفمبر 2026؛ إكمال فحص الوثيقة وحزمة المصادر: 13 نوفمبر 2026. إصدار التنفيذ `v1.2.0-rc.9`؛ كود العمل على `feature/frontend-v2` عند `ab530ea` قبل تحرير الوثيقة. لم تُغيّر هذه الجولة كود التطبيق ولم تستأنف رفع GitHub.

## مصادر المحتوى

1. عينة `Project Document - BIT.zip`: راجعت ملفات الفصول السبعة وإعدادات الهوامش والخط. اتُّبعت أدوار المقدمة والدراسات والمنهجية والتحليل والتصميم والتنفيذ والاختبار والخاتمة. صححت عناوين الفصول العامة في العينة لتصف موضوعها. لم يُنسخ مشروع الأدوية أو أسماؤه أو نتائجه، ولم تُعامل العينة كدليل رسمي مستقل.
2. Word v7: راجعت هيكل الفصول 1–4 وتقادم وصفه عن الأدمن والمنتجات والنسخ والاسترجاع. لم يُحوّل دون مراجعة ولم يُعدّل الملف القديم.
3. الكود الفعلي: ملفات `backend/main.py`, `search_engine.py`, `segmenter.py`, `category_routing.py`, `image_preprocessing.py`, `catalog_config.py`, `catalog_metadata.py`, `product_grouping.py`, `demo_catalog.py`, `demo_catalog_api.py`, `admin_auth.py`, `catalog_backup.py`, `search_observability.py`, `request_validation.py`، وواجهة HTML/JavaScript وأداة التشغيل.
4. التجارب الأصلية وأدلة rc.9 في سجل الملحق B. السكربت `generate_evidence.py` يولّد الجداول والرسمين من النتائج ويحتفظ ببصماتها في `evidence_snapshot.json`، دون إعادة استدلال تاريخي أو تعديل ملفات التقييم.
5. المراجع الـ18: أوراق أصلية، صفحات ناشرين، مستودعات وبطاقات نماذج رسمية، وكتاب استرجاع المعلومات ووثائق FastAPI وSQLite وargon2-cffi. كل مرجع مستخدم فعليًا بأمر استشهاد، مع بيانات BibTeX ورابطه الأصلي.

## المراجعة الجوهرية

- وصف الأدمن المحلي وCRUD والصور المتعددة والأسعار الاختيارية والتوفر والنسخ والاسترجاع وفق التنفيذ.
- قصاصة SAM2 في الكود ذات خلفية بيضاء؛ القناع الأخضر RGBA. لم تُنقل عبارة «قصاصة شفافة» الخاطئة من دليل API القديم.
- FAISS الحالي CPU وIndexFlatIP دقيق؛ CUDA مخصص لاستدلال النماذج عند توفره.
- مراكز فئات الكتالوج الأصلي تختلف عن بوابات التصنيف المحافظ للكتالوج المضاف. لم تُنسب عتبات الأخير للأول.
- تجميع المنتجات المضافة يعتمد أفضل صورة لكل منتج؛ تجميع الكتالوج الأصلي يعتمد مجموعات مراجعة محددة، وليس استنتاج SKU تلقائيًا.
- النماذج مسبقة التدريب؛ داتا train معرض بحث وليست تدريبًا جديدًا للنموذجين.
- فصل صحة الفئة والتشابه البصري والهوية، وبين التاريخي وتجهيز التطبيق، وبين validation وtest.
- عينة الهوية سبع مجموعات لا 14 منتجًا مستقلاً. نقاط الاتجاه العكسي من المساعد قبل النتائج وليست أقنعة بشرية مرجعية.
- البصمات لا تنفي هوية مشتركة عبر صور مختلفة. أرقام البطاقات وUUID ليست SKU موثقًا من بائع.
- ضمان revision موصوف لحفظ المحتوى والحذف المراجع؛ ذُكرت حدود مسار تعديل البيانات القديم بدل تعميم الضمان على كل API.
- لم تُختلق تواريخ أو درجة علمية أو تكلفة مالية أو أدوار فردية أو نتائج مسح مستخدمين أو توقيعات.
- لم يُوصف نشر runtime المتوقف بأنه مكتمل. الوثيقة الحالية نسخة تسليم وليست مسودة.

## التحقق لهذه النسخة

نجحت 197 حالة Python و43 JavaScript و55 تحققًا للأدلة والبايتات، و32 فحص HTTP باستدلال فعلي و15 تحققًا للإدارة والاسترجاع على نسخة معزولة تطابق الكود النشط. لقطات المتصفح فعلية للرفع والبحث الكامل والتحديد والاعتماد والبحث المحدد، والدخول للإدارة وفتح المحرر وإلغائه والخروج. لم تتغير قواعد المستخدم الشخصية.

أُعيدت قراءة مواصفات الجهاز ونسخ مكتبات المشروع. التشغيل الحي لهذه الجولة استخدم CPU على الجهاز نفسه؛ سجل rc.9 السابق يوثق CUDA. ليست أعداد الفحوص دقة بحث أو شهادة لكل الأجهزة والمتصفحات. فحوص الملف النهائي والصفحات والمراجع محفوظة في `VERIFICATION_SUBMISSION.json`. التوقيعات والختم الفعليان لا ينتجان آليًا.
