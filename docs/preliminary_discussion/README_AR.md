# ملفات المناقشة الأولية المعتمدة

هذه ملفات المناقشة الأولية لمرحلة **rc.7**، وليست وثيقة التسليم النهائي المطلوبة باللاتكس. التطبيق تقدم الآن إلى [rc.8](../PRESENTATION_RC8_AR.md) بإدارة منتجات مكتملة محليًا؛ ستُحدّث مواد التسليم النهائي بعد اعتماد نطاق الوظائف.

إصدار التطبيق المصاحب: `v1.2.0-rc.7` على `feature/frontend-v2`، بتاريخ 11 أكتوبر 2026.

- [تقرير المشروع Word v7](AI_Visual_Product_Search_Chapters_1_to_4_Preliminary_v7.docx): 51 صفحة، والغلاف المعتمد والاستشهادات التفاعلية محفوظة.
- [عرض المناقشة PowerPoint v5](AI_Visual_Product_Search_Preliminary_Discussion_v5.pptx): 19 سلايد، يبدأ بصورة الغلاف نفسها ويذكر أرقام التحقق حين إصدار rc.7.
- [شرح السلايدات بالعربية v2](Slide_Explanation_Arabic_v2.docx): دليل المذاكرة، محدث لنسخة الشرائح الحالية وأعداد الاختبارات الجديدة.
- [تقرير الإصدار والتحقق](../PRESENTATION_RC7_AR.md).
- [مراجعة الجاهزية ومتابعة إغلاق الملاحظات](READINESS_REVIEW_2026_10_11_AR.md).

النسخ الأقدم تبقى محفوظة محليًا للرجوع إليها، لكنها ليست ملفات التسليم لهذه النسخة. ملفات Downloads السابقة لا تُحدّث تلقائيًا؛ افتح الملفات المحددة أعلاه لتجنب عرض نسخة قديمة.

شغّل التطبيق من اختصار **Fashion Search Demo** على جهاز الفريق، وانتظر اكتمال تحميل النماذج قبل بدء العرض. تفاصيل السيناريو في [تعليمات العرض المحلي](../LOCAL_PRESENTATION_AR.md). النماذج والبيئة الافتراضية والصور وقواعد البيانات موارد محلية، فلا يكفي تنزيل Git وحده لتشغيلها على جهاز آخر.
