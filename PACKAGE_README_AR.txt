حزمة Graduation_AI المراجعة - الإصدار السادس
التاريخ: 21 سبتمبر 2026

طريقة التركيب:
1. احتفظ بنسخة احتياطية من مجلد المشروع الحالي.
2. فك الحزمة داخل مجلد المشروع الرئيسي ووافق على استبدال الملفات.
3. لا تحذف مجلدي models أو datasets أو offline_wheels الموجودين عندك.
4. فعّل البيئة الافتراضية وشغّل:
   python -m uvicorn app:app --host 127.0.0.1 --port 8000
5. افتح http://127.0.0.1:8000
6. أول بحث سيبني فهرس 3068 صورة وقد يستغرق عدة دقائق مرة واحدة.

الحزمة لا تحتوي على:
- النماذج الثقيلة داخل models.
- مجموعة البيانات الكبيرة datasets/clothing_small؛ يجب أن تبقى النسخة الموجودة عندك.
- الحزم المحملة مسبقًا داخل offline_wheels.
- فهارس FAISS وقاعدة المراقبة المولدة؛ يعاد بناء الفهرس عند الحاجة.
- البيئة الافتراضية وملفات PyCharm وملفات __pycache__.
