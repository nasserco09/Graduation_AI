البنية التحتية

كيف يعمل محرك البحث البصري؟

خطوات متزامنة لتحويل الصورة المدخلة إلى متجهات رياضية دقيقة والبحث عنها في أجزاء من الثانية

01

معالجة وتحسين الصورة (Preprocessing)

إزالة التشويش، توحيد الأبعاد، وتعديل إضاءة وتباين الصورة لضمان استقرار النموذج في مختلف بيئات التصوير.

تصحيح الإضاءة والألوان إزالة التشويش والقص
02

استخراج الخصائص (Feature Extraction)

استخدام شبكة عصبية تلافيفية عميقة لاستخراج سمات الأقمشة، الألوان، الأكمام، والياقات وتحويلها إلى متجه عددي.

تمييز نوع النسيج والقصة تحليل الدرجات اللونية
03

فضاء التضمين المتجهي (Vector Space)

إسقاط المتجه في فضاء عالي الأبعاد (512-D) بحيث تكون القطع المتشابهة في الشكل متقاربة هندسياً.

تضمين عالي الدقة (512-D) تقارب هندسي للمتشابهات
04

البحث بالتشابه (Cosine Similarity)

حساب جيب التمام الزاوي ومطابقة المتجه مع آلاف القطع المفهرسة في قاعدة البيانات وعرض أفضل Top-K تطابقات.

خوارزمية جيب التمام الزاوي استرجاع فوري لأفضل النتائج

توثيق الواجهة البرمجية (REST API)

أمثلة لكيفية إرسال الصور واستقبال الرد بصيغة JSON من خلال نقطة النهاية

POST /api/search_image 
curl -X POST "https://api.fashionsearch.ai/api/search_image" \
  -H "Accept: application/json" \
  -F "file=@/path/to/my_clothing_photo.jpg" \
  -F "top_k=5"
import requests

url = "https://api.fashionsearch.ai/api/search_image"
files = {'file': open('outfit.jpg', 'rb')}
data = {'top_k': 5}

response = requests.post(url, files=files, data=data)
results = response.json()

for item in results['results']:
    print(f"[{item['similarity']*100:.1f}%] {item['title']} - {item['product_id']}")

كيف يتم حساب نسبة التشابه والتطابق؟

يتم تحويل الصورة إلى متجه مميز (*Embedding Vector*) من 512 بُعداً، ثم يتم حساب زاوية التشابه (*Cosine Similarity*) بين متجه صورة المستخدم ومتجهات جميع المنتجات في الكتالوج، حيث القيمة 1.0 تعني تطابقاً تاماً.

ما هي صيغ وأحجام الصور المدعومة؟

يدعم النظام صيغ (PNG, JPG, JPEG, WebP) بحجم أقصى يصل إلى 8MB، كما يدعم التقاط الصور الحية عبر كاميرا الهاتف أو الحاسوب واللصق المباشر من الحافظة (Ctrl+V).

هل يعمل البحث إذا كانت خلفية الصورة غير بيضاء؟

نعم، تم تدريب النموذج على استخراج خصائص الملابس مع تجاهل الخلفيات المعقدة والإضاءات المختلفة للتركيز على القطعة الأساسية.

هل يمكن ربط المحرك مع متجر إلكتروني قائم؟

بالتأكيد! يوفر النظام REST API بسيط لرفع الكتالوج ومزامنة المنتجات واستقبال استعلامات البحث بسهولة.
